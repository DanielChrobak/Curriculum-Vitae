# Product

## Platform

web

## Users

Hiring managers and recruiters scanning Daniel Chrobak's experience and technical work.

## Product Purpose

A public curriculum vitae and portfolio. A visitor can identify Daniel's current role and technical focus, review the evidence behind his work, and contact him or print a copy of the CV.

## Positioning

Daniel founded SlipStream and builds its Windows capture-to-browser pipeline across the C++23 host, GPU video encoding, QUIC/WebTransport, and TypeScript browser client. His public Hyper-V and network audio projects demonstrate related systems work.

## Capabilities and Constraints

- The site is a static Vite build for GitHub Pages. Its CV content and native disclosures work without JavaScript.
- Preserve public project and credential links, section and project anchors, filters, theme selection, and printing.
- SlipStream's source is private. Its architecture illustrates the implementation without implying measured latency or universal hardware support.
- GitHub stars are a dated build-time snapshot. Credentials retain their issuer links and earned dates.

## Evidence on Hand

The HTML contains experience, project descriptions, education and architecture diagrams. Public repository statistics and 13 credentials are stored in source data and injected at build time.
