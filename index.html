Behind the project +

The problem

GPU-enabled virtual machines require more than assigning a device. Guest drivers need to match the host, and changes need a reliable recovery path.

The implementation

Device discovery, per-adapter assignment, driver-plan previews, verified copies, and interrupted-operation recovery. Desktop, console, and headless workflows share the same PowerShell tooling.

Support depends on the GPU, host driver, and guest Windows version. The repository documents prerequisites and community foundations.

Behind the project +

The problem

Desktop streaming crosses native Windows APIs, GPU encoders, transport, browser decoding, and user input. Each stage has its own capabilities and failure modes.

The implementation

A C++ Windows host and TypeScript/Vite client using WebTransport and WebCodecs. Hardware encoding, monitor selection, host audio, clipboard and file exchange connect the native and browser experiences.

Source repository is private. Diagrams illustrate the architecture; they do not represent a live session or measured performance.
